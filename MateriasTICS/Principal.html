Materias TICS

Estas cuatro materias constituyen el núcleo técnico del desarrollo de software moderno: juntas permiten analizar y estructurar la información (Análisis y Base de Datos), construir la lógica interna del programa mediante componentes reutilizables (Programación Orientada a Objetos), diseñar la interfaz visual e interactiva accesible desde navegadores (Diseño Web) y adaptar estas soluciones a aplicaciones nativas y multiplataforma para dispositivos portátiles (Programación Móvil).

Programacion Orientada a Objetos (POO)

  • Eje Principal: Enseñar a estructurar el código mediante clases u objetos reutilizables en lugar de bloques de código sueltos.
  • Lenguajes Clave: Java, C#, Python.
  • Resultado Esperado: Crear software modular, escalable y fácil de mantener.

Analisis y base de datos

  • Eje Principal: Diseñar la estructura donde se guardará la información y crear las reglas para consultar o modificar esos datos.
  • Herramientas Clave: SQL (MySQL, PostgreSQL), MongoDB, Diagramas UML / MER.
  • Resultado Esperado: Sistemas capaces de guardar y procesar información de forma rápida y segura.

Diseño web

  • Eje Principal: Construir la interfaz de usuario e interacción visual de un sitio accesible desde un navegador.
  • Tecnoligías Clave: HTML5, CSS3, JavaScript, React / Figma.
  • Resultado Esperado: Páginas y aplicaciones web adaptables a cualquier pantalla (Responsive Design).

Programación Móvil

  • Eje Principal: Desarrollar aplicaciones optimizadas para pantallas táctiles, hardware móvil (cámara, GPS) y consumo eficiente de batería/datos.
  • Entornos Clave: Kotlin (Android), Swift (iOS), Flutter / React Native (Multiplataforma).
  • Resultado Esperado: Aplicaciones funcionales listas para publicarse en Google Play o App Store.
