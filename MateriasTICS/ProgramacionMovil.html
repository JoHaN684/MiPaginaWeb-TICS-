Programación Móvil

¿Qué es?

Es el proceso de diseño, desarrollo, pruebas y despliegue de aplicaciones de software diseñadas específicamente para ejecutarse en dispositivos portátiles inteligentes, como teléfonos móviles, tabletas, relojes inteligentes (smartwatches) y otros dispositivos móviles. Abarca desde la concepción de la idea y la interfaz de usuario hasta la optimización del rendimiento y la integración con servicios en la nube.

Tecnologías principales:

  • Nativas:
    • Android: Kotlin, Java y Jetpack Compose.
    • iOS: Swift y SwiftUI.
    • Permiten acceder al máximo rendimiento del dispositivo y a todas sus funciones de hardware de forma directa.
  • Multiplataforma: (Cross-Platform)
    • Flutter (lenguaje Dart).
    • React Native (lenguaje JavaScript / TypeScript).
    • MAUI / Xamarin (lenguaje C# / .NET).
    • Permiten escribir un solo código fuente y desplegar la aplicación tanto en Android como en iOS, reduciendo tiempos y costos de desarrollo.

Enfoque principal:

  • Optimización de recursos: Gestión eficiente de batería, consumo de memoria RAM, almacenamiento interno y rendimiento del procesamiento.
  • Adaptabilidad de diseño: Creación de interfaces de usuario responsivas que se adapten a diferentes tamaños, resoluciones y orientaciones de pantalla.
  • Diseño de UX/UI: Implementación de interfaces táctiles, gestos intuitivos (deslizar, pellizcar, tocar) y diseño centrado en el usuario.
  • Integración con hardware (APIs del dispositivo): Uso e integración de herramientas nativas como cámara, GPS/geolocalización, sensores (acelerómetro, giroscopio), Bluetooth, biometría (huella dactilar/reconocimiento facial) y notificaciones push.
  • Conectividad y persistencia: Manejo de conexiones de red inestables, almacenamiento local de datos (SQLite, Room) y sincronización con bases de datos en la nube.
