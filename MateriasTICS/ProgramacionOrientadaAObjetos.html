Programación Orientada a Objetos (POO)

¿Qué es?

Un paradigma de programación fundamental que organiza el diseño de software alrededor de "objetos" (instancias de clases) en lugar de funciones o lógica pura. Permite modelar entidades y comportamientos del mundo real, facilitando la creación de código modular, reutilizable, mantenible y escalable en proyectos de cualquier envergadura.

Pilares fundamentales:

  • Encapsulamiento: Ocultar los detalles de implementación interna y restringir el acceso directo a los datos de un objeto, exponiendo únicamente métodos públicos (getters y setters) para proteger la integridad del estado interno.
  • Herencia: Permitir que una clase nueva (clase derivada o hija) reutilice y extienda los atributos y métodos de una clase existente (clase base o padre), promoviendo la jerarquía y evitando la duplicación de código.
  • Polimorfismo: Ofrecer la capacidad a diferentes objetos de responder de manera distinta ante una misma llamada a un método, permitiendo tratar objetos de distintas clases de forma uniforme mediante interfaces o clases abstractas comunes.
  • Abstracción: Ocultar la complejidad técnica subyacente y mostrar solo las características esenciales del objeto relevantes para el sistema, simplificando el modelado del software.

Lenguajes comunes:

Java, C++, Python, C#, PHP, Swift, TypeScript, Kotlin, Ruby.
